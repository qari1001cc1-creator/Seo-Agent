OPTION A - Drag & Drop (easiest, no install)
  1. Go to https://app.netlify.com  -> login (Google/GitHub)
  2. Click  "Add new site"  -> "Deploy manually"
  3. Drag the  test_site  FOLDER  onto the page
  4. Wait ~30 seconds -> you get  https://yourname.netlify.app

OPTION B - Netlify CLI
  1. Install:  npm install -g netlify-cli
  2. cd C:\Users\Dell\Desktop\SEO-AGENT\test_site
  3. netlify deploy --prod --dir=.  (first time: login + pick name)

AFTER DEPLOY
  - Your live URL will look like  https://something-1234.netlify.app
  - Test it in the browser:  / , /about , /services , /contact ,
    /blog/top-10-seo-tips , /blog/web-design-trends , /privacy
  - /services-gone.html  -> intentionally returns custom 404 page
  - /sitemap.xml  and  /robots.txt  work

LINK SEO-AGENT TO THE LIVE SITE
  1. Edit  C:\Users\Dell\Desktop\SEO-AGENT\.env
        DOMAIN=https://yourname.netlify.app
  2. Restart the dashboard (run.bat)
